Jacob: Project Overview

Mission

What problem does this project address?
Jacob addresses the limitations of Edward, the existing daily checkin generator used by TM8s. Although Edward assists users in generating end-of-day (EOD) checkins, it relies primarily on calendar events, resulting in limited context for accurately summarizing a user's daily work. Jacob expands the available data sources by incorporating information from Google Calendar, Gmail, and Slack into a unified activity log, enabling AI-assisted generation of more grounded, comprehensive, and accurate daily checkins.
What is the goal of this project?
Jacob is an iteration of Edward, the existing daily checkin generator. Edward primarily generates checkins from calendar events and their associated durations. Jacob extends this capability by incorporating additional workplace data sources including Slack conversations and Gmail activity, to provide richer context for AI-assisted checkin generation. The objective is to improve both the completeness and accuracy of generated checkins while reducing the manual effort required from TM8 members.
What are some key features that define the product?
  • AI-assisted daily checkin generation grounded in workplace activity.
  • Multi-source activity aggregation from Google Calendar, Gmail, and Slack.
  • Unified activity log generated through a backend pipeline before AI processing.
  • Support for conversational refinement through a Custom GPT capable of asking clarification questions when evidence is insufficient.
  • Extensible architecture that allows future integration of additional workplace data sources.
  • Complete project documentation covering requirements, design, implementation, testing, deployment, and maintenance.
What makes this product different from others?
Unlike its predecessor, which relies primarily on calendar events for checkin generation, Jacob aggregates multiple workplace data sources to produce more grounded summaries of completed work. Rather than simply summarizing scheduled events, it combines contextual information from Slack conversations, Gmail communication, and calendar activities before generating the final checkin. The integrated Custom GPT is also trained using organization-specific guidance and can ask follow-up questions whenever the available evidence is insufficient, reducing hallucinations and improving auditability.

Scope

What is the scope of this project?
The scope of Jacob is to provide an AI-assisted workflow for generating data-driven daily checkins using workplace activity data. It includes authentication with supported services, retrieval of user activities, orchestration of collected data into a unified activity log, and AI-assisted generation of checkins. The system also supports generating checkins for previous dates, helping TM8 members complete backlogged reports using historical workplace activity.
What are the high-level assumptions or ground rules for the project?
The accuracy of generated checkins depends on the availability and completeness of workplace activity data. Users remain responsible for reviewing generated outputs before submission. The system is intended to assist (not replace) the user's judgment when preparing daily reports.
What are we not going to do?
Jacob is not intended to replace existing workplace communication tools or project management systems. It does not infer work that has no supporting evidence, nor does it generate reports without user review. The project also does not attempt to integrate every possible productivity platform during its current development scope.
Is this project part of a larger effort?
Yes. Jacob is an extension of the Edward Daily Checkin Generator. It builds upon Edward's existing calendar-based functionality while expanding the platform with additional data sources and AI-assisted workflows. Users may continue using Edward's standard calendar-based checkin generation or opt to use Jacob for richer, context-aware checkin generation.

Status

What is the status of this project?
Jacob is currently under active development within the 10-week timeframe of Thinking Machines' internship program. Core functionality, including Calendar, Gmail, Slack integration, backend activity orchestration, and AI-assisted checkin generation, is being implemented incrementally, with additional refinements planned throughout the mentioned period.

Applicability

Who should use this product?
Jacob is intended for TM8s who submit daily checkins as part of their regular workflow. It is particularly useful for developers, consultants, and project teams who manage work across multiple workplace platforms and wish to reduce the manual effort involved in preparing accurate daily reports. Project maintainers, future developers, and stakeholders may also use the accompanying documentation to understand the system architecture, implementation decisions, and project workflow.
How can users get started?
  1. Review the Edward project documentation to understand the existing workflow and architecture.
  2. Authenticate with supported workplace accounts (Google Calendar, Gmail, and Slack).
  3. Generate a unified activity log from connected workplace services.
  4. Use the integrated AI assistant to generate grounded daily checkins.
  5. Developers and maintainers should refer to the repository documentation, architecture documents, and implementation guides for setup and maintenance.
