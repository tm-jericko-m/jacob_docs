F-01: Connect a Slack Workspace

Priority:Expected
Effort:Days
Risk:1-Risk
Functional area(s):Authentication, Slack Integration
Use case(s):UC-05
Description:

Users authorize their Slack workspace to allow Jacob to retrieve workplace conversations for activity generation.

Precise Details:

  • Uses Slack OAuth authentication.
  • Slack authorization may be cancelled.
  • Slack can be reconnected if authorization expires.
Notes and Questions:
  • Slack integration is optional for Standard Edward.

F-02: Retrieve Workplace Activity

Priority:Essential
Effort:Weeks
Risk:2-Risks
Functional area(s):Activity Aggregation
Use case(s):UC-02 UC-06 UC-14
Description:

Retrieve workplace activity from Google Calendar, Gmail, and Slack to produce a unified activity log for AI-assisted checkin generation.

Precise Details:

  • Retrieves activity from Calendar, Gmail, and Slack.
  • Supports retrieval for a selected date.
  • Merges activity into a single activity log.
Notes and Questions:
  • Retrieval continues when one service is temporarily unavailable.

F-03: View a Unified Activity Summary

Priority:Essential
Effort:Days
Risk:Safe
Functional area(s):User Interface
Use case(s):UC-02 UC-08

Users can review a human-readable summary of the retrieved workplace activity before generating AI-assisted checkins.

F-07: Generate Grounded Checkins Using Workplace Activity

Priority:Essential
Effort:Weeks
Risk:2-Risks
Functional area(s):Artificial Intelligence
Use case(s):UC-10 UC-15
Description:

Jacob generates checkins grounded only on retrieved workplace activity to improve accuracy and reduce unsupported information.

  • Grounded output is preferred over complete output.
