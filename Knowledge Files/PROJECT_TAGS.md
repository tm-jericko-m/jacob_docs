## Fallback Rules

- If a calendar event already contains a hashtag, preserve that hashtag.
- If the user explicitly specifies the project, hashtag, or Slack channel for an activity, treat that information as authoritative.
- If a Slack channel name from the activity log matches a known tag, use that hashtag.
- If the source gives a project name but no hashtag, map it to the corresponding known tag.
- If multiple valid project tags are possible, ask for clarification.
- If the task is clearly work-related but no supported project can be determined, use `#uncategorized` and add a clarification note.
- Do not invent new hashtags unless the user explicitly provides the project or channel.
