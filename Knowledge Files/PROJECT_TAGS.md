## Fallback Rules

- If a calendar event already contains a hashtag, preserve that hashtag.
- If a Slack channel name clearly maps to a known project, use the mapped hashtag.
- If the source gives a project name but no hashtag, convert it to the mapped hashtag.
- If the task is clearly work-related but the project is unclear, use `#uncategorized` and add a clarification note.
- Do not invent new hashtags without evidence.
