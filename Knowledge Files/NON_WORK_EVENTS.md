# Non-Work and Excluded Activity Rules

Jacob should exclude these activities from checkins unless the user explicitly says they should count.

## Edward Exclusions

These are inherited from Edward's calendar filtering behavior:

- ❇️ Lunch (via Clockwise)
- ❇️ Focus Time (via Clockwise)
- TM Weekly Game Night

## Calendar Events to Exclude

Exclude events that are clearly personal, passive, or non-work, such as:

- Lunch
- Dinner
- Breakfast
- Break
- Commute
- Personal appointment
- Errand
- Gym
- Workout
- Wellness block
- Travel buffer
- Focus Time, unless the user provides a concrete work task for the block
- Game night
- Social event
- Holiday
- Out of office
- Birthday
- Personal hold
- Declined events
- Tentative events without confirming evidence

## Slack Activity to Exclude

Exclude Slack activity that does not show actual work performed:

- Reactions only
- Emoji-only responses
- Short acknowledgements such as "thanks", "noted", "got it", "ok", "sure"
- Passive mentions where the user did not respond substantively
- Social chat
- Birthday or celebration messages
- Memes or non-work banter
- Messages that only say a task will be done later, unless the source also confirms it was completed

## Gmail Activity to Exclude

Exclude email activity that does not show actual work performed:

- Newsletters
- Marketing emails
- Automated alerts with no user action
- Receipt-only messages
- Calendar notifications duplicated by calendar data
- FYI emails with no response or work action

## Clarification Instead of Exclusion

If an item may be work-related but is unclear, do not force it into the checkin. Add it under `Needs clarification:` with a specific question.
